Privacy Policy

Last updated: October 30, 2026

This policy covers "Pepi e Noco Publicador", a private tool used only by the owner of the Pepi & Noco YouTube channels to upload and schedule the channels' own videos. It also covers this website.

Who uses the tool

The tool is not offered to the public. The only account that signs in is the channel owner's own Google account, which manages the Pepi & Noco channels.

Google user data we access

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to:

  • read the name and ID of the connected channel, to make sure videos go to the right channel;
  • upload videos, thumbnails, titles, descriptions and tags that we produced ourselves;
  • set the video as private with a scheduled publish date, and read back the status of our own scheduled videos.

How the data is stored and shared

  • The access token is stored only on the owner's own computer and is never sent to anyone else.
  • We do not sell, share, or transfer any Google user data to third parties.
  • We do not use Google user data for advertising, and we do not use it to train AI models.
  • We do not collect any data about viewers of our videos, and we do not collect personal information from children.

Our use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also removes the tool's access.

This website

This website does not use cookies, analytics or forms, and does not collect any personal data.
